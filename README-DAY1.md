# FixPlus Day 1 starter

This is the Day 1 staged version of the FixPlus app.

## Run
1. Extract this folder.
2. Open the `FixPlus-Day1-starter` folder in VS Code.
3. Run `npm install`.
4. Run `npx expo start` (or `npx expo start --web`).

## Day 1 scope
- Expo Router root and tab navigation
- Light/dark theme toggle (in-memory for Day 1)
- Service catalogue data
- Reusable Screen and ServiceCard components
- Home screen
- Placeholder tabs for features planned on later days

The Day 1 context intentionally does not include favourites, bookings, ratings, or AsyncStorage. Those are added in later stages.
