# FixPlus — Day 2

Includes the complete Day 1 Home screen and adds the working Services directory and Service Details screen.

## Day 2 changes
- Search services by name, category, or description
- Filter by category and sort by price/rating
- Open service details from Home or Services
- View descriptions, included items, pricing and ratings
- Save favourite services locally

Bookings and profile are unchanged from Day 1.

## Run
```bash
npm install
npx expo start
```

## Commit Day 2
Copy these files into your existing FixPlus project (do not replace the .git folder), then:
```bash
git add .
git commit -m "Day 2: Implement Services and Service Details screens"
git push
```
